    How this ontology was built
    1. Read the source. We extracted text, tables and presenter notes from the PowerPoint. Each excerpt kept its slide number and location.
    2. Group the material. We used the lecture sections as the hierarchy and grouped passages about the same idea into one named topic.
    3. Type the links. AI drafted relationships between topics using a small set of predicates. Each link records its direction, rationale and supporting slides.
    4. Check the grounding. We reviewed the topics and claims against the deck. The build checks that links resolve to real topics and that fact excerpts can be found in the source.

    How the talk models feedback and decisions

    The same model applies to the tutor and the research lab. Slides 30–31 describe what changes. Slide 32 shows how the next run uses the update, and slide 34 shows how to test its effect.

    Evidence
    New input that bears on a record, such as a learner’s answer or an experiment result.
    Record
    A stored preference, piece of domain knowledge, learner assessment or working hypothesis. The record links to its evidence.
    Update
    A change to an identified record. The application’s rules specify what evidence can justify it and who reviews it.
    Agent decision
    A next action chosen using the relevant state, such as asking a follow-up or proposing an experiment.
    Evaluation
    A repeatable case that checks the resulting state and scores the next action. A comparison can measure the effect of making the saved update available.

      The inner loop chooses settings using the outer training data. The outer loop evaluates the resulting fitted model on the outer test fold.

      • Describes tuning in the inner loop.
      • Describes evaluation on the held-out fold in the outer loop.

      Slides 8, 9, 10 · Basic

    • Apply Trace one outer split through cross_val_score and RandomizedSearchCV. When does the outer test fold enter the computation?

      • Uses the outer training portion for both inner search and refit.
      • Uses the outer test fold only after fitting, for outer scoring.
